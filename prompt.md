# AI Prompts Used During the Challenge

## Prompt 1 — Project Planning

I need to implement a Java project that supports searching, sorting, and pagination within a limited time. Help me design a clean MVP architecture using OOP concepts and multithreading. Prioritize a working implementation before advanced features.

---

## Prompt 2 — Project Architecture

Suggest a clean Java project structure for a search, sort, and pagination system. The project should demonstrate encapsulation, abstraction, polymorphism, Java Collections, error handling, and multithreading.

---

## Prompt 3 — Search Implementation

Generate a Java service layer design for searching records by name and category. The search should be case-insensitive and should return all records when the search keyword is empty.

---

## Prompt 4 — Sorting Implementation

Provide a clean Java implementation for sorting records by name, date, and numeric value. Support both ascending and descending order and avoid modifying the original dataset.

---

## Prompt 5 — Pagination Implementation

Provide Java pagination logic that accepts a list of records, page number, and page size. Include validation for invalid page numbers and page sizes.

---

## Prompt 6 — Multithreading

Show how to use ExecutorService, Callable, and Future to execute the search and sorting workflow in a worker thread while allowing the main thread to receive the processed result.

---

## Prompt 7 — Testing

Suggest foundational test cases for search, sorting, pagination, empty search input, and invalid pagination input.

---

## Prompt 8 — Documentation

Help create documentation that explains the project overview, architecture, design decisions, setup instructions, testing, trade-offs, and future improvements.
